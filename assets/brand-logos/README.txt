Brand Logos
-----------

Drop brand-approved press-kit SVG (or PNG) logos here. The site falls back to
the Simple Icons public CDN if a local file is missing, so this is the place
to swap in production-ready logos as Zay receives them from each brand.

Expected filenames (referenced by about.html and make-statements/index.html):
  nike.svg
  adidas.svg
  ubisoft.svg

Microsoft renders as a typographic wordmark by design (Simple Icons no longer
hosts the Microsoft logo). To swap Microsoft to an image, edit both
about.html and make-statements/index.html and add `microsoft.svg` here.

Press-kit sources:
  Nike      — https://news.nike.com/news/nike-resources
  Adidas    — https://www.adidas-group.com/en/media/media-resources
  Ubisoft   — https://news.ubisoft.com/en-us/branding
  Microsoft — https://news.microsoft.com/microsoft-brand/
